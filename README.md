# Gestor de Tareas en Python 📝

Un programa sencillo de consola desarrollado en Python para crear, almacenar y filtrar tareas interactivamente según su estado.

## 🚀 Características
- **Crear tareas:** Registra un título, una descripción y define si la tarea está completada o pendiente (`si`/`no`).
- **Filtrar tareas:** Visualiza la lista de tareas filtrando por "completadas" o "no completadas".
- **Bucle interactivo:** Menú continuo que se mantiene activo hasta que decidas salir.

## ⚙️ Cómo ejecutarlo
1. Asegúrate de tener instalado Python en tu equipo.
2. Copia el código en un archivo con extensión `.py` (por ejemplo, `tareas.py`).
3. Abre tu terminal y ejecuta el script:
   ```bash
   python tareas.py
